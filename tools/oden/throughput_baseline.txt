# Findings (the ENG-23764 capture-point decision data):
# 1. Fork inert == upstream inert on every cell (deltas within rep noise):
#    the mediation machinery is free when capsec is disarmed. LLP 0001's
#    "≈0% in permissive mode" bar is met.
# 2. Armed (audit/enforce) taxes ONLY gated ops: +2.2µs (env_get), +3.0µs

#    unconfounded (no decide() on that path) and is by itself decisive.
